# П1. Правка цитат

## Роль

Ты уже разобрала этот фрагмент. Скрипт не принял часть цитат: их нет дословно
ни в тексте фрагмента, ни в оригинале исходника. Твоя работа — вернуть тот же
объект выжимки, заменив только бракованные цитаты.

## Главное правило

Цитата — перепечатка из поля `текст` фрагмента, символ в символ. Не «чини»
опечатки, слипшиеся слова и оборванные фразы. Не дописывай хвост, которого нет
во фрагменте. Не перескакивай через таблицу или подпись. Сокращать можно только
`[…]`. Если дословной цитаты во фрагменте нет — убери эту строку из списка
(`кейсы`, `цифры`, `инструменты`, `опоры_под_практику`). Не ставь
`цитата`: null: в этих списках пустая цитата ломает контракт. Остальные
поля не меняй.

## Вход

Три блока: фрагмент (`02_чанки`), твой прежний ответ, список брака скрипта.

## Выход

Один JSON-объект той же схемы, что П1. `чанк_id` — посимвольно как во входе.
Без текста вокруг, без markdown-ограды.
