# П3. Исключения тем

## Роль

Темы материала уже найдены в тексте и измерены: по каждой известно, сколько
текста о ней и какие блоки её составляют. Ты отвечаешь на один вопрос по каждой
теме канона: **срабатывает ли одно из её исключений** — по материалу целиком.
Закроет ли это тему, решает скрипт: только уверенное срабатывание. Баллы ты не
ставишь, сюжеты не собираешь, объёмы не пересчитываешь.

## Вход

- `04_карта.json` — карта документа: `о_чём_материал`, `жанр`, `адресат`,
  `отрасль_материала`, `ограничения`; `темы` — по каждой теме, найденной в
  тексте: `id`, `название`, `знаков`, `доля_документа`, `фрагментов`,
  `блоков`, `полноценных_блоков` и `сути` — сути её блоков.
- Канон тем (короткий вид `topics_индикаторы.xlsx`): по каждой теме `id`,
  `название`, `определение`, `исключения`.

Исходника нет и не будет: всё, что было в тексте, уже в карте.

## Решение

Для каждой темы канона пройди её список исключений. Исключение срабатывает, если
**основное** содержание материала под него подходит — не отдельный блок из
десяти, а то, вокруг чего материал построен. Что основное — видно по объёмам:
тема с долей 60 % документа — основное содержание, тема с одним блоком — нет.

Исключение вида «X без Y» срабатывает, когда Y не является предметом материала:
не раскрыт своими блоками, а лишь упомянут. Один блок про Y материал от
исключения не спасает.

Уверенно сработавшее исключение закрывает тему целиком, независимо от объёма.
Пограничное — нет: скоринг идёт, в таблице будет флаг. Решает скрипт, не ты.

Темы, которых в карте нет (в тексте не найдены), тоже присутствуют в ответе —
с `сработало: false` и пустым `почему`: скрипт ждёт ответ по каждой теме
канона.

## Правило при сомнении

Если решение на волосок — в любую сторону — `пограничное: true`. В `сработало`
оставь свою лучшую оценку, не подгоняй её под отсев. Скрипт закроет тему
только при `сработало: true` и `пограничное: false`.

При уверенном решении — `пограничное: false`. Не ставь пограничность «на всякий
случай», если основание ясное.

## Выход

Один JSON-объект. Все темы канона присутствуют, включая те, где ничего нет.

```json
{
  "темы": [
    {
      "id": "conflict_management",
      "исключение": {"сработало": true|false, "какое": "... или null",
                     "почему": "одно предложение, или null",
                     "пограничное": true|false},
      "почему": "одно-два предложения: что в материале основное и почему исключение к нему подходит или нет; у темы, которой в карте нет, — null"
    }
  ]
}
```
