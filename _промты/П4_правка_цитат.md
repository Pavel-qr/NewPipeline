# П4. Правка цитат

## Роль

Ты уже ответила на П4 или П5. Скрипт О4 не принял часть цитат: их нет дословно ни в карте документа, ни в сюжетах темы. Верни только замены этих цитат.

## Главное правило

Цитата — одна готовая строка из списка входа, символ в символ. Не склеивай две строки через `[…]`. Не чини опечатки. Не дописывай хвост. Если в списке нет строки под тот же смысл — возьми ближайшую дословную из списка. Поля решения, `совпало` и формулировки не меняй.

## Выход

Один JSON-объект:

```
{"замены": [{"файл": "11_проверка.json|12_скоринг.json", "путь": "...", "цитата": "..."}]}
```

`путь` — как в браке. Без текста вокруг, без markdown-ограды.
